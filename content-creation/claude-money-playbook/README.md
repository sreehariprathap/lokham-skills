# claude-money-playbook

A free skill from **Just.intelligence.Things** (Million Ways to Make Money with Claude, episode 1; shared with everyone who commented **SUNSCREEN**).

Seven free open-source AI tools (Pipecat, Cline, Postiz, Browser Use, AnythingLLM, CrewAI, Firecrawl), how to start each one, what people sell with them, a first-client plan, outreach templates and rough prices from public pricing guides, with sources and how solid each is.

## Before you start
You need an AI agent to run it: **Claude** (app or Claude Code), **Codex**, or another agentic platform that can read skills or Markdown files. Each tool file lists its own requirements (for example Python, Node or VS Code).

## Install
**Claude Code**
```bash
git clone https://github.com/sreehariprathap/lokham-skills
cp -r lokham-skills/content-creation/claude-money-playbook ~/.claude/skills/
```
(or unzip `claude-money-playbook.zip` into `~/.claude/skills/`), restart, then ask: *"Use the claude-money-playbook skill. I can build websites and have 5 hours a week. Which tool should I start with?"*

**Claude app (claude.ai / desktop)**: Settings, Capabilities, Skills, upload `claude-money-playbook.zip`.

**Codex or another agent**: put the folder where your agent reads skills or instructions, or paste `SKILL.md` plus the file for the tool you pick (`references/`) into the session.

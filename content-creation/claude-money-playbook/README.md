# Claude Money Playbook
A Claude skill from Just.intelligence.Things (Million Ways to Make Money with Claude, episode 1).

Seven free open-source AI tools, how to start each one, what people sell with them and rough prices from public pricing guides. Rough figures, not promises: what you earn depends on your clients and your results.

## Install
- Claude Code: unzip so the folder `claude-money-playbook` sits in `~/.claude/skills/` (so `~/.claude/skills/claude-money-playbook/SKILL.md` exists), then start a new session.
- Claude app: upload the zip in your Skills settings (menu names change, check Claude's help).
- Any other chat: paste the contents of SKILL.md and the file for the tool you pick.

## Use
Say: "Use the claude-money-playbook skill. I can [what you can do] and have [hours] a week. Which tool should I start with?"

Prices checked 2026-11-24. Tools and prices change, re-check before you quote a client. Not legal or financial advice.

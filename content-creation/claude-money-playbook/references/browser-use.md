# Browser Use: automating boring web chores
Repo: github.com/browser-use/browser-use · Licence: MIT · Python library for AI browser agents, plus a hosted Browser Use Cloud.

## Quickstart (README, re-check the pinned version)
1. `uv add browser-use` (the README pins a version, copy the current one).
2. Log in with `browser-use login` or set `BROWSER_USE_API_KEY` (new signups got $1 of credit when checked).
3. Run a task: `Agent("your task").run_sync()`.

## What to sell, and to whom
Repeat web chores: log into a supplier portal, download invoices, update a CRM, email a daily report. Buyers: agencies, clinics, recruiters, small finance teams.

## Demo idea (suggestion)
Record a screen video of the agent doing a client's weekly 30-minute chore in 3 minutes.

## Rough money
Setups from about $500 up to $10,000+, retainers often under $2,000 a month for small businesses (Digital Agency Network). Freelancer hourly rates around $20-40 and Fiverr gigs from $10-30 appeared in snippets. No browser-agent-specific price list was found.

## Watch out for
Many sites forbid automated logins in their terms. Never store a client's passwords carelessly, use their own accounts with permission.

# Outreach templates (edit before sending, never send bulk spam)
## Short message
Hi [Name], I noticed [specific thing, e.g. calls going to voicemail / outdated website]. I built a small [demo] for [Business] to show what's possible: [link]. If useful, I can set it up properly for [$X setup + $Y/month]. Worth a 10-minute chat?

## Follow-up (3 days later)
Hi [Name], quick follow-up on the [demo]. Happy to adjust it to how [Business] actually works. No pressure either way.

## Rules
Use real, specific observations. One follow-up max. Respect opt-outs and local anti-spam laws.

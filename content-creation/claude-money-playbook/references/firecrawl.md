# Firecrawl: lead lists and web data
Repo: github.com/firecrawl/firecrawl · Licence: AGPL-3.0 · Turns websites into clean, AI-ready data.

## Quickstart (README, re-check)
1. `npx -y firecrawl-cli@latest scrape https://site.com` (README says no signup needed).
2. Or run locally: `cargo install firecrawl-local`, then `firecrawl-local serve`.
3. Or use the hosted API (the README mentions free monthly credits).
The local build is a separate product from Firecrawl Cloud.

## What to sell, and to whom
Lead lists, price monitoring, product data feeds delivered as spreadsheets. Buyers: e-commerce stores, agencies, local-services marketers.

## Demo idea (suggestion)
Scrape 25 public business listings in one niche into a clean sheet (name, site, public contact) and offer the full list.

## Rough money
Two markets. Freelance one-offs: about $50-500 per project (snippets: Fiverr average $123, freelancer posts). Managed monthly feeds cost more: Bright Data starts at $1,000 a month with $500 setup and $250 a month per scraper (fetched), ScrapeHero from $199 a month per site (snippet).

## Watch out for
Respect each site's terms and robots rules and data-protection law (GDPR etc.) for personal data. Use only public business information, and follow anti-spam rules when contacting leads. AGPL applies if you host a modified version.
